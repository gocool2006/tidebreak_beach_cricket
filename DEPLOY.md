# Publish Tidebreak for anyone to play

The playable game files and original beach-ground artwork are already uploaded to this public repository.

## One-time GitHub Pages setup

1. Open [repository settings](https://github.com/gocool2006/tidebreak_beach_cricket/settings/pages).
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open **Actions**, select the latest **Deploy Tidebreak to GitHub Pages** run, and choose **Re-run all jobs**.
4. Once it succeeds, share: https://gocool2006.github.io/tidebreak_beach_cricket/

The included workflow publishes only the playable HTML, CSS, JavaScript, and original ground artwork. Match saves stay in each player's browser and are not shared. Browser storage is removed if the browser clears that site's data.
